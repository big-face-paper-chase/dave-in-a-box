HOW TO DRIVE IT

drums — one char per 16th note. x hit, X ACCENT, . rest. 
drums({
  kick:  "x...x...x...x...",
  snare: "....x.......x...",
  chat:  "x.xxx.xxx.xxxxx."
})
drum names: kick snare clap chat ohat perc
bass / keys — one token per 16th note. note names or . rest. 
bass("c2 . c2 eb2 . g1 . .",
  { wave: "sawtooth",
    cutoff: 700, decay: 0.3 })
waves: sawtooth square triangle sine
rules of the box
  • each box holds one expression — it hot-reloads as you type
  • strings can be any length — 16 steps = 1 bar, 32 = 2 bars, go wild
  • space play/stop · 1–8 presets · a airhorn · s siren
  • presets are just code — fire one, then mangle it. that's the whole sport.

built for chase, in the spirit of DJ Dave — pre-built blocks, performed live. when you outgrow the box, the real thing is strudel.
